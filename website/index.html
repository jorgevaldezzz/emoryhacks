Figma → Cursor

This folder ships with TalkToFigma MCP so you can read and update designs from Cursor while you build the site.

  1. Install Bun.
  2. Open this website/ folder in Cursor so .cursor/mcp.json loads.
  3. Run the TalkToFigma WebSocket relay: bunx cursor-talk-to-figma-mcp@latest socket flow, or follow the package docs (bun socket).
  4. In Figma, run the Cursor MCP plugin and join the same channel.
